# Project Ascend

Project Ascend is a local-first AI-powered productivity desktop application built with Python, PySide6, and SQLite.

## Vision

Help students focus, study consistently, and understand where their time actually goes while keeping all personal data private.

## Current Features

- Tomorrow Planner
- Dashboard
- Persistent Activities
- Study Session Timer
- Local SQLite Database
- Activity Completion Tracking

## Tech Stack

- Python 3.13
- PySide6
- SQLite
- Qt Designer (future)
- Git (planned)

## Current Version

v0.4

## Philosophy

Less Friction.
More Focus.
