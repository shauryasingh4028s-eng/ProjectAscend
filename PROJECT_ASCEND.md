# Project Ascend

## Vision
Project Ascend is a privacy-first AI productivity desktop application built with Python.

## Core Principles
1. Privacy First
2. Modular Architecture
3. Expandable
4. Beginner-Friendly Code
5. Professional UI

## Goals
- Improve productivity
- Reduce procrastination
- Track study time
- Track distractions
- Build better habits
- Keep all user data local

## Planned Modules

### Phase 1
- Dashboard
- Live Clock
- Daily Schedule
- Study Timer
- Task Manager

### Phase 2
- Activity Tracking
- Screen Time
- Statistics
- Reports

### Phase 3
- Focus Mode
- Website Blocking
- App Blocking
- Streaks

### Phase 4
- AI Coach
- Daily Review
- Habit Analysis
- Schedule Suggestions
