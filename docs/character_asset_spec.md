# Project Ascend — Character Asset Specification (Engineering & Asset Contract)

## Overview
This document specifies the technical contract and folder hierarchy for Project Ascend's character identity artwork.

The visual assets defined here will be generated by Gemini using a dedicated visual generation pipeline and placed directly into the application's asset directory.

**NO UI CODE CHANGES ARE REQUIRED** when final character artwork PNGs are dropped into the canonical folder structure. The application automatically detects, loads, and caches these assets, falling back gracefully to neutral geometric avatar renders if an asset slot is unpopulated.

## 3. Evolution Stage Hierarchy & Visual Progression

Evolution stages are derived strictly from player level:

### Stage 1: Initiated (Level 1, 0 XP)
- **Visual Identity**: Novice practitioner attire, simple robes or minimal gear.
- **Aura & Lighting**: Subtle ambient lighting, clean lines, calm baseline energy.

### Stage 2: Established (Level 10, 900 XP)
- **Visual Identity**: Refined garments, equipped tools of trade (compass, blueprint, blade, quill).
- **Aura & Lighting**: Secondary energy ring, stronger accent lighting.

### Stage 3: Ascended (Level 25, 4,650 XP)
- **Visual Identity**: Ornate robes/armor, stylized glowing crests and levitating elemental elements.
- **Aura & Lighting**: Vibrant radiance, dual-tone gradient background glow.

### Stage 4: Sovereign (Level 50, 10,900 XP)
- **Visual Identity**: Sovereign majesty, golden crown/halo crest, full mastery garments.
- **Aura & Lighting**: Full sovereign aura, luminous energy, cosmic accent accents.

## 4. Image Dimensions & Safe Area Specifications

- **Native Resolution**: `512 × 512` pixels (rendered down smoothly by UI to `130 × 130`, `54 × 54`, or `30 × 30`).
- **Background**: 100% Transparent (Alpha Channel = 0).
- **Margin / Safe Area**: Subject must fit inside a central circular/rounded square boundary with **15% padding** on all edges to ensure energy auras do not get clipped by UI card borders.
- **Focal Point**: Centered horizontally and vertically, optimized for square ratio framing.

---

## 5. Software Pipeline & Fallback Contract

1. **Asset Lookup**:
   - `CharacterAssetManager.get_character_pixmap(character_id, stage, width, height)` resolves the asset path on disk.
2. **Caching**:
   - Loaded images are cached in `QPixmapCache` and internal memory dictionary by key `char_pixmap_{id}_s{stage}_{w}x{h}_{theme}` to prevent repeated disk reads.
3. **Graceful Fallback**:
   - If an asset file is absent or corrupted, `CharacterAssetManager` generates a theme-aware, intentional geometric avatar with character emblem, radial gradient, and stage indicator pill.
